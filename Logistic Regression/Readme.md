# 🔵 Logistic Regression – Machine Learning Project

This repository contains a complete implementation of **Logistic Regression** using Python and Scikit-Learn.  
The project uses the **Kaggle Titanic Dataset** for binary classification — predicting whether a passenger survived or not.

---

## 📌 **What is Logistic Regression?**
Logistic Regression is a **classification algorithm** that predicts the probability of a class (0 or 1).  
It uses the **sigmoid function** to convert linear output into probabilities:

\[
P(y=1|x) = \frac{1}{1 + e^{-z}}
\]
